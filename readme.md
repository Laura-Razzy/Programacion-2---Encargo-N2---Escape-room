# **DESCRIPCIÓN GENERAL:**

Se deberá crear un prototipo de videojuego en **primera persona** de género de **Terror** en el que el jugador deberá escapar de una “**Escape Room**” realizando distintos **puzzles** mientras que **merodea un enemigo inteligente**.

El enemigo deberá tener una **IA (“Inteligencia artificial”) compleja**, capaz de hacer algunas acciones que lo demuestren como un ser pensante, **algunos ejemplos son**: Patrullar por distintos puntos, detectar ruidos del jugador y acudir a dicha zona, perseguir al jugador, interactuar con el entorno, etc. Esto con la intención de que el enemigo se sienta como un ser realmente **pensante e inteligente que proponga un desafío al jugador**.

También, se espera que el lugar contenga **distintos objetos que se podrán guardar en el inventario**. En determinados momentos, el jugador deberá **abrir su inventario y usar alguno de los elementos para resolver distintos puzzles**, **algunos ejemplos son**: Curar su vida, abrir puertas, silenciar sus pasos, etc.

El inventario del jugador deberá ser visible mediante un menú para poder elegir qué objeto queremos usar / consumir.

Como es normal, si el enemigo nos atrapa, habremos perdido la partida. Por el contrario, si mediante el uso de nuestros objetos y el sigilo logramos escapar, habremos ganado.

En resumen, se deberá crear un prototipo de terror en el que deberemos encontrar objetos, usarlos y completar puzzles con la intención de abandonar el lugar mientras escapamos de un enemigo inteligente.

***(Se espera que el prototipo cuente con la integración de menús, elementos artísticos y sonoros acorde a lo solicitado)***
